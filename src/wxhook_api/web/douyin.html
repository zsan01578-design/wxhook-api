解析设置

在此设置解析来源和默认群名单。群聊管理中单独配置的群功能优先。

默认直接在本项目中解析，无需另开服务或填写接口地址。小红书要求登录时，可在本机 parse-video.local.yml 配置本人 Cookie；失败原因会显示在解析记录中。

选择“指定解析接口”时必填；选择 parse-video-py 时作为抖音解析失败后的备用接口。不要附加 ?url= 参数，地址含账号标识，只保存到本机配置。

填写群 ID，不是群昵称。可以先在微信消息中查看群 ID。

回传需要该群启用自动保存。视频以 MP4 文件发送，静态图片按原顺序作为图片消息发送。
